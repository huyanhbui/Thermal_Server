# Roadmap and milestones

The roadmap prioritizes a reliable data/authentication foundation, a real Host agent, a clean operating UI, exact LLM readiness and streaming, tunnel lifecycle, and production-like acceptance. Shipping is gated by green tests, no P0/P1 defects, no orphan process, no secret leakage, and model smoke tests.

External milestones require resources outside the repository: Internet/model storage, a Cloudflare hostname/token for Named Tunnel, and a second Windows worker for true multi-node acceptance.
